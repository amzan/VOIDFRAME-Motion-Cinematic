## Quick Installation

Install VOIDFRAME globally for Google Antigravity:

```bash
npx skills add https://github.com/amzan/VOIDFRAME-Motion-Cinematic --skill voidframe -a antigravity -g
```

Restart Antigravity and ask your agent to activate
the VOIDFRAME skill.
