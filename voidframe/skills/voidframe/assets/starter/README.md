# Motion proof starter
Copy to a new episode folder. Requires Node 22 and network for initial `npm install` (approval first). Run `npm test` for pure pose/IK tests, `npm run check` for type checking and `npm start` for browser editor at http://localhost:9000. In editor choose 1920x1080, 24 fps, full range, FFmpeg exporter, Render; output is in `output/`. No audio is supplied. No unattended render command is bundled. The demo is one continuous 8-second horizontal shot, not the separate vertical three-shot planning example in templates. Its vector primitives, walk motion and door contact are technical proxies, not final-quality acting or foot-locking. Rework with authored assets, contact constraints and separate vertical staging before production. The optional two-link solver is tested independently; not wired into the demo. Commit a generated lockfile after successful install; no lockfile included because registry access was unavailable at packaging time.
